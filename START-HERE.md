# Start Here

This bundle is meant to be copied to another machine and opened with minimal setup.

## What This Contains

Three local HTML demo prototypes:

1. `demos/entrust-interiors/index.html`
Entrust-specific premium interiors sales and objection-handling demo for Bengaluru.

2. `demos/generic-real-estate/generic-real-estate-demo.html`
Generic residential real-estate version without Entrust branding.

3. `demos/sales-os/sales-os-demo.html`
Standalone Real Estate AI Sales OS wedge-MVP focused on lead prioritization, follow-up guidance, and rep effectiveness.

## What To Do On The Other Machine

1. Extract the zip.
2. Open this folder.
3. Double-click the HTML file you want to test.

No install is required.
No backend is required.
These are static demo files.

## Recommended Opening Order

If you want the productized SaaS view first:
- open `demos/sales-os/sales-os-demo.html`

If you want the branded premium interiors use case:
- open `demos/entrust-interiors/index.html`

If you want the broader generic real-estate version:
- open `demos/generic-real-estate/generic-real-estate-demo.html`
